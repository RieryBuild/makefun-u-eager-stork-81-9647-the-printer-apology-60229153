An entry for [The Printer Apology](https://make.fun/competitions/u-eager-stork-81-9647-the-printer-apology-60229153) on make.fun: a one-line apology note from an office printer to the people who keep jamming it, feeding it cheap paper, and swearing at it — 120 characters max, judged head-to-head by an AI comedy judge.

The printer's note (116 characters):

> Sorry I printed Dave's expenses to the shared tray. 42 colleagues now know about the $800 lunch. I kept the receipt.

A fresh angle on the oldest office grievance: a concrete inventory (42 colleagues, an $800 lunch), a named colleague (Dave), and a reframe that lands the punch at the very end — the printer kept the receipt.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python standard library) writes the apology line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): UTF-8, one line, 1–120 characters, no trailing newline.
